# 《第 91 分钟》视觉方向

## 设计主张

它不是常见的“霓虹电竞仪表盘”，而是一套在深夜更衣室里被不断翻阅的数字比赛档案。暗色面板承担专注，细窄册边、编号、时间戳和广播切线编码真实信息；球队色只在决定、焦点和关键赛况中出现，不平均涂满页面。

## 视觉语法

- **Display**：Anton，仅用于站名、比分、分钟数和重大结果；中文标题回退到黑体系统栈。
- **Body**：中文使用 PingFang SC / Microsoft YaHei，西文和数字使用本地打包 Inter。
- **Utility**：Inter 的大写、较宽字距和等宽数字，表现 Notebook 编号、时间、属性变化。
- **Base**：`#0a0a0c`；面板 `#141417`；边框 `#2a2a35`；正文 `#ededed`；次文 `#888899`。
- **Club primary**：只用于当前选择、焦点、比赛领先信号和主题线。
- **Risk**：警示橙红只用于倒计时最后三秒和紧急新闻，不与球队色混用表达含义。

## Signature：三视角纸边

三个主区域左上都有 `NOTEBOOK 01/02/03` 书签，边缘使用 2px 主题线与浅刻度。编号不是三个分开的足球学科：01 记录同一事件如何被谈论，02 记录它如何改变球员与俱乐部，03 记录它如何落入训练与比赛。移动端底部导航继续使用相同编号，使桌面三栏和移动标签保持同一心智模型。

## 密度与节奏

```text
稀疏开场 → 紧凑注册 → 高密度职业中控 → 单一焦点决定 →
沉浸比赛日 → 结果回声与返回
```

职业中心允许信息密集，但一次只突出一个行动；六阶段生涯图按时间展示 56 个可能体验，不另开学科空间。比赛日移除侧栏，把比分、播报和选择放在纵向一条阅读线上。数据库使用较慢节奏和更宽行距，给当前处境所需的术语解释留出恢复空间。

## 动效职责

- 300ms opacity + translateY：说明路线/面板进入，不等待动画结束才能操作。
- 压力条：表达剩余决定窗口；文字秒数始终给出等价信息。
- 主题切换：转会后的颜色过渡解释所属俱乐部改变。
- Toast：连接选择和数值后果。

减少动效时取消位移、缩放、平滑过渡和压力条动画；保留立即出现的状态与文字倒数。无自动播放音频，无持续媒体。
