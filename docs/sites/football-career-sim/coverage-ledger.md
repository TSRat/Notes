# 足球与人生覆盖账本

目标不是堆积百科栏目，而是确保一名球员可能经历的不同足球面向都能成为职业选择、赛季结果或长期结局。

| 体验领域 | 当前可玩入口 | 长期影响 |
| --- | --- | --- |
| 青训与成长 | 三封邀请、位置改造、训练投入、教育安排 | OVR 曲线、适应性、首秀路径 |
| 一线队竞争 | 替补耐心、租借、训练表现、教练信任 | 出场、角色、合同与转会市场 |
| 战术与位置 | 转型、战术再学习、专精或多面性 | 适配、教练信任、职业寿命 |
| 合同与经纪 | 首份合同、续约、解约风险、经纪人建议 | 稳定性、声望、转会与压力 |
| 转会与跨文化 | 豪门/中游/本土选择、语言、搬迁与旅行 | 俱乐部层级、归属感、发展速度 |
| 比赛关键时刻 | 首秀、德比、领先/落后决策、伤停补时 | 比赛结果、声望、信任与成就 |
| 伤病与医疗 | 带伤比赛、恢复、手术、复出节奏 | 身体状态、峰值、职业长度 |
| 国家队 | 青年/成年队进入、赛事压力、俱乐部冲突 | 出场、国际声望、专属成就与结局 |
| 媒体与公众 | 采访、社交媒体、商业邀约、舆论压力 | 声望、压力、品牌与更衣室关系 |
| 家庭与个人生活 | 陪伴、迁居、长期分离、心理恢复 | 幸福感、稳定性、风险承受能力 |
| 队内关系与领导 | 队友、队长职责、更衣室分歧 | 信任、归属、领导型结局 |
| 财务与退役 | 合同安全、商业机会、学习、教练入口 | 健康退役、第二职业和博物馆记录 |
| 俱乐部与足球文化 | 真实城市、主场、颜色、身份标签、术语抽屉 | 情感代入与选择语境，不直接加成 |

## 数据覆盖

- 15 个精选国家或地区竞赛生态。
- 60 家真实俱乐部，每个生态 4 家；每条记录含来源与置信度。
- 37 个关键事件模板，覆盖青训、突破、黄金期、老将与退役阶段。
- 59 个术语用于选择现场解释。
- 24 项成就与 10 类结局。

## 明确保留的未来入口

- 经审核的真实球员、教练与管理人员数据。
- 更多女子足球、低级别联赛、青少年和半职业路径。
- 俱乐部历史时期数据，而不是把当前球队画像永久化。
- 赛制、法规与竞赛名单的版本化更新。

扩展时仍需遵守：事实字段有来源和日期；模拟字段明确标注；人物权利与图像授权独立审核。
