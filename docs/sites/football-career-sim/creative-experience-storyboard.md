# 《第 91 分钟》创意体验故事板

## 体验弧

```text
身份落点 → 创建新秀 → 进入三视角中控 → 读取压力 → 作出决定 →
看到数值回声 → 进入比赛 → 场上抉择 → 穿行六个生涯阶段 → 退役转型
```

## 路线与场景

| ID | 场景 | 注意目标 | 情绪 | 出口 |
| --- | --- | --- | --- | --- |
| 00 | 青训注册 | 站名、职业承诺、姓名/位置/球风 | 克制期待 | 创建档案进入 `/career` |
| 01 | 职业中控 | 当周焦点、球员状态、同一事件的三个观察窗口 | 信息压力 | 决策、百科、比赛日、生涯图 |
| 01A | 经纪人窗口 | 两个可理解且有后果的选项 | 时间紧迫 | Toast 与属性/主题变化 |
| 02 | 百科 | 术语分类、短解释、深链 | 恢复与学习 | 返回原路线 |
| 03 | 比赛日 | 比分、分钟、场上选择 | 聚焦紧张 | 结果回写、返回中控 |

## 直接进入

每条路线的持久顶栏都显示《第 91 分钟》与“球员生涯模拟器”。`/career` 没有存档时明确显示“访客体验档”；`/database` 说明百科只负责解释职业现场并深链回相应经历；`/match/:id` 在比分之前命名比赛双方与赛事。任何路线都能回到首页或职业中心。

## 场景规则

### 00 / Academy Intake

- 内容：用一句话解释玩家将从青训走到退役，并在过程中处理训练、战术、伤病、身份、合同、治理和比赛选择。
- 交互：表单原生 label；空姓名、超长姓名给出修复方式。
- 动效：身份块与表单顺序进入；减少动效时同步出现。
- 移动：注册卡先于装饰性赛季编号，键盘弹起后仍可滚动到按钮。

### 01 / Career Hub

- 内容：真实周次、下一场比赛、三项核心属性、三条新闻和数据库术语。
- 交互：桌面三栏；平板百科抽屉；移动通过 01/02/03 底部导航切换全屏面板。
- 失败：存档解析失败回退访客档并 Toast 说明；数据库空结果不影响生涯。
- 印象贡献：三个窗口同时回答“外界发生了什么、我和俱乐部处于什么状态、我需要理解什么”；它们共同解释同一刻，而不是把足球拆成三门课。

### 01A / Pressure Decision

- 内容：选项同时给出语言后果暗示，但不提前泄露精确数值。
- 交互：12 秒窗口，剩余秒数读屏；选择后禁用重复提交。
- 超时：按钮降至 0.3、`not-allowed`，显示“窗口已关闭”；不自动替玩家选择。

### 02 / Database

- 内容：每项解释术语是什么、为什么此刻有用；不是只有定义标题。
- 交互：搜索、分类、深链到职业或比赛情境；Tooltip 支持悬停、焦点、触摸点击。
- 失败：无结果时显示当前关键词和清除操作。

### 03 / Matchday

- 内容：资格赛双方、比分、事件时间线和一次边路处理选择。
- 交互：无 Hub 普通消息；决定结果进入播报并回写战术/体力。
- 静态等价：动画、主题光晕全部关闭后，比分、顺序、决定与返回仍完整。
