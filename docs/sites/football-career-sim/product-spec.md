# 《第 91 分钟》产品与实现规范

## 主题锚点

- **Subject**：一款以新闻、职业决策和比赛文字播报驱动的足球球员生涯模拟器。
- **Audience**：喜欢足球叙事、经营选择与短回合网页体验的中文玩家；无需足球战术专业知识。
- **Single job**：读懂当前职业处境，在压力窗口内作出一次有后果的选择。
- **Constraints**：单页应用、简体中文、无真实队徽、核心 JS 未压缩前低于 500KB、最新 Chrome/Safari/Firefox、移动 Safari 安全视口。

## 印象契约

- **Feel**：像坐在比赛日控制室，时间紧迫但信息从不混乱。
- **Recognize**：这是关于同一名球员从街头与青训、职业突破、巅峰、转折到退役转型的可玩人生。
- **Remember**：Notebook 01 舆情、Notebook 02 俱乐部、Notebook 03 比赛记录不是三门分开的学科，而是观察同一职业事件的三个窗口。
- **Do**：注册球员、处理首个经纪人抉择、进入比赛日并完成一次场上决定。

## 公共入口的 3 / 10 / 30 秒

- 3 秒：显示《第 91 分钟》、足球球员职业生涯模拟器、当前赛季档案语义；动画不阻塞阅读。
- 10 秒：显示青训注册表，明确姓名、位置和球风会创建档案。
- 30 秒：进入 `/career`，看到三本 Notebook、球员属性、首个限时决定和可理解的后果。

## 路由与直达恢复

| 路由 | 核心任务 | 直达恢复 |
| --- | --- | --- |
| `/` | 创建青训档案 | 可跳过动效；合法默认值使流程可立即开始 |
| `/career` | 浏览情报、状态、百科并决策 | 无存档时载入标注为“访客体验档”的默认新秀，不出现空白页 |
| `/database` | 检索足球术语 | 保留项目身份、返回职业中心；无结果时给出清除搜索操作 |
| `/match/:id` | 阅读比赛时间线并作场上决定 | 未知 ID 显示可恢复错误；有效 ID 隐藏非紧急外部消息 |

## 核心可玩闭环

1. 在首页创建球员档案。
2. 职业中心展示新闻、球员雷达与带压力计时器的选择。
3. 选择后 reducer 原子更新体力、战术理解、声望或俱乐部。
4. Toast 用自然语言宣布结果；动态主题随转会平滑切换。
5. 比赛日提供文字事件和场上选择；结果回写档案。
6. 六个连续生涯阶段承载 56 个可能体验，覆盖训练、战术、合同、医疗、身份、治理、社区、科技、审美与转型；任何内容都通过球员当下处境进入。
7. 数据库解释当前事件里的术语，并深链回对应生涯情境；它不是独立课程目录。

## 数据边界

`src/data/*.json` 是 MVP 权威内容；`src/data/db.ts` 是唯一适配器。`career-experiences.json` 是统一生涯图，`terms.json` 是按需解释层，二者通过 ID 双向关联。未来 API 必须返回与 `PlayerState`、`Club`、`NewsEvent`、`MatchEvent`、`CareerExperience`、`EncyclopediaTerm` 等价的数据，不让组件依赖传输细节。

存档仅写入浏览器 `localStorage`，没有账户、网络同步、支付或真实球员数据。损坏存档回退到访客档，并提供清晰恢复提示。

## 成功标准

- 三条关键路线在 320px、768px、1440px 宽度下无横向溢出。
- 按钮具备 default、hover、focus-visible、pressed、disabled 状态。
- 倒计时既有视觉条，也有屏幕阅读器读秒文本；减少动效时不播放 width 动画。
- 每次属性变化都有 Toast 文本反馈。
- 转会选择在一个渲染周期内更新主题 tokens。
- 所有导航为语义链接或按钮，键盘可达且焦点可见。
