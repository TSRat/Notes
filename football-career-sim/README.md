# 第 91 分钟 · 足球球员职业生涯模拟器

《第 91 分钟》是一款以真实俱乐部世界为背景、以模拟球员为主角的中文职业生涯游戏。一次完整生涯从 16 岁开始，约在 32–39 岁结束；普通赛季由系统推进，玩家处理真正会改变道路的合同、位置、伤病、转会、国家队、家庭与比赛时刻。

当前版本包含 15 个国家或地区的顶级竞赛生态、60 家真实俱乐部、37 个关键事件模板、59 个情境化足球术语、24 项跨生涯成就和 10 类结局。俱乐部使用名称、城市、主场、传统配色和文字缩写，不使用官方队徽、球衣或真实人物肖像。首发世界中的球员、教练、经纪人和管理人员均为模拟角色，数据结构为以后加入经审核的真实或历史人物预留了来源与权利字段。

## 玩法原则

- 事实明确、结果不确定：选项说明已知取舍，不展示成功率；所有随机结果由可复现种子驱动。
- 足球主导、人生穿插：竞技成长、位置、出场、合同和国家队是主轴，教育、家庭、媒体、商业与退役规划改变风险和结局。
- 多种人生都能成为好结局：稳定的一线队生涯、国家队贡献、城市英雄、旅欧开拓者、健康退役等都可成立；球星和传奇仍然稀有。
- 一条时间线：知识、比赛、合同和人生事件在同一职业档案里出现，不拆成永久并列的“Notebook”。

## 路由

| 路由 | 用途 |
| --- | --- |
| `/` | 开场与继续存档 |
| `/create` | 创建模拟球员并选择起点 |
| `/career` | 职业时间线与关键决策 |
| `/career/player` | 球员档案、OVR 与能力状态 |
| `/world` | 全球俱乐部网络、来源与术语 |
| `/match/:id` | 沉浸式关键比赛 |
| `/season/:year` | 赛季账本 |
| `/museum` | 跨生涯成就与存档管理 |
| `/database` | 兼容入口，重定向至 `/world?panel=glossary` |

## 本地运行

```bash
npm install
npm run dev
```

## 检查与构建

```bash
npm run lint
npm test
npm run build
npm run check:bundle
npm audit --audit-level=high
```

核心实现位于：

- `src/engine/`：可复现随机数、OVR、赛季推进、事件、转会、国家队、成就与结局。
- `src/data/world/`：竞赛生态、俱乐部、来源、关键事件、成就与结局 JSON。
- `src/storage/`：以 IndexedDB 为主的版本化多存档仓库、导入导出和旧原型迁移。
- `src/pages/` 与 `src/components/`：响应式 SPA 与比赛/时间线界面。
- `dist/`：由构建生成、用于精确 commit 预览的静态镜像；不要手工编辑。

设计、内容、分析与 QA 交付文档位于 `../docs/sites/football-career-sim/`。
